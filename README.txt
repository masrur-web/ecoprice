ECOPRICE — PWA-пакет

Содержимое:
- index.html — приложение-калькулятор
- manifest.webmanifest — настройки установки
- sw.js — офлайн-кэширование
- icons/ — иконки приложения

Как использовать:
1. Разместить ВСЕ содержимое этой папки на HTTPS-хостинге.
2. Открыть опубликованный адрес в Chrome на Android.
3. Для установки как PWA выбрать меню Chrome → «Установить приложение» или «Добавить на главный экран».
4. Для получения APK открыть https://www.pwabuilder.com/, вставить опубликованный HTTPS-адрес и выбрать Android → Other Android, затем скачать пакет. Доступность APK зависит от текущих настроек сервиса.

Важно:
- Список расчётов сохраняется в localStorage конкретного браузера/домена.
- При переносе с локального HTML на новый домен ранее сохранённые записи автоматически не переносятся.
- Для первого размещения на новом домене сделайте экспорт CSV из старой версии, если там есть важные записи.
